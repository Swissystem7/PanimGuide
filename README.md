# פנים־מדריך / PanimGuide

מדריך עברי, מימין־לשמאל, חינוכי ואינטראקטיבי ל**מורשת הטקסטואלית** של חכמת הפנים (חכמת הפרצוף) במסורת היהודית־קבלית.

האתר בנוי כאתר סטטי בלי תלויות ובלי CDN, ומיועד להגשה ב־GitHub Pages.

## מה זה

- סקירה ממוקדת מקורות: היכן מופיעה הלשון (מקרא, קומראן, גאונים דרך הרמב״ן, זוהר פרשת יתרו / רזא דדיוקנין, רמב״ם, ייחוסים מודפסים לר׳ חיים ויטאל, קבלה הלכתית מאוחרת).
- חוקר תווי הפנים: תרשים SVG מופשט עם מחוונים לשדות שהמקורות דנים בהם, וציטוט או «לא נמצא מקור» לכל בחירה. כל מצב של המחוונים ניתן לשיתוף בקישור (`explorer/index.html?eyes=2&lips=3`), עם כפתור «העתקת הקישור» בדפדפנים שתומכים ב־Clipboard API (הדף רק כותב ללוח, לעולם לא קורא ממנו); הקישור מקודד מיקומי מחוונים בלבד, אף פעם לא תמונה או אדם.
- מילון מושגים מאויר בתרשימי SVG מופשטים בלבד.
- הקשר היסטורי: פיזיוגנומיה בתרבויות, דחייתה המדעית, ולומברוזו / פרנולוגיה / מדע גזע / אוגניקה.
- דף מקורות עם כל ציטוט ותאריך בדיקה (13 באוגוסט 2026).

השפה הראשית היא עברית. הציטוטים האקדמיים באנגלית נשמרים במקורם כשהמקור באנגלית.

## מה זה במכוון לא

האתר **אינו** כלי אבחון ואינו «קורא פנים».

הוא מסרב במפורש ל:

- ניתוח, צילום, העלאה או ניקוד של פנים של אדם חי
- מצלמה, קלט תמונה, זיהוי פנים
- הסקה על אישיות, כישרון, מוסר או גורל של איש
- המצאת ציטוט, מקור או מספר עמוד

המסורת מוצגת כשכבת תרבות וטקסט. היא **אינה שיטה מדעית לשפיטת בני אדם**. הדחייה הזו מקושרת באתר לקונצנזוס המודרני נגד פיזיוגנומיה (בין השאר תערוכת ספריית הרפואה הלאומית של ארה״ב, הצהרות אונסק״ו על גזע, והנזקים המתועדים של לומברוזו, פרנולוגיה ואוגניקה).

אם אי אפשר לאמת מקור, נכתב **«לא נמצא מקור»**. ייחוס מודפס של ספר לר׳ חיים ויטאל אינו מוצג כאימות מחברות.

## מבנה

| קובץ | תוכן |
| --- | --- |
| `index.html` | שער, גבולות קשיחים, מפת האתר |
| `explorer/index.html` | חוקר תווי הפנים — תרשים ומקורות |
| `js/explorer.js` | מחוונים, תרשים SVG, טענות מצוטטות |
| `overview.html` | סקירה ממוקדת מקורות |
| `glossary.html` | מילון מושגים + SVG מופשט |
| `history.html` | הקשר היסטורי, קונצנזוס, נזקים |
| `sources.html` | כל הציטוטים ותאריכי בדיקה |
| `css/style.css` | עיצוב עצמאי, כהה/בהיר, הדפסה, נגישות |
| `js/app.js` | תפריט, ערכת נושא, סינון מילון |
| `favicon.svg` | סמל גאומטרי (לא פנים) |

אין תלויות, אין בונדלר, אין פונטים חיצוניים, אין אנליטיקה. `package.json` קיים רק בשביל `npm test`.

## נגישות ועיצוב

- `lang="he"` ו־`dir="rtl"` בכל הדפים
- דילוג לתוכן, מיקוד מקלדת, `aria` בתפריט ובסינון
- ניגודיות כהה/בהיר (`prefers-color-scheme` + מתג ידני)
- מובייל תחילה; עיצוב הדפסה שמרחיב את פרטי המילון
- `prefers-reduced-motion`

## בדיקות

```
npm test
```

בדיקות `node:test` בלי תלויות (`test/`): כל דף `lang="he"` ו־`dir="rtl"`, כל קישור ועוגן פנימי קיימים, אין מצלמה / תמונות / סקריפטים חיצוניים, והחוקר עקבי (מחוונים ב־HTML מול `DEFAULTS` ו־`LABELS`, עוגני ציטוט ב־`sources.html`), וחיפוש המילון מתעלם מניקוד, מגרש/גרשיים מול גרש/מירכאות מהמקלדת וממקף עברי מול מקף רגיל (`רמב"ן` מוצא את `הרמב״ן`). רצות גם ב־GitHub Actions.

## הרצה מקומית

פתחו את `index.html` בדפדפן, או משרת סטטי כלשהו משורש הריפו.

GitHub Pages: שורש הענף `master`.

## רישוי תוכן

הציטוטים שייכים למקורותיהם. התרשימים, המבנה והטקסט המקשר נכתבו עבור הפרויקט.
